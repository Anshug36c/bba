## ✅ How to use these notes

1. **Read** — har unit line-by-line. Coloured boxes: 📘 definition, 🗣️ Hinglish matlab, 🌍 real-life example, 🧠 memory trick, 🧮 formula, 🎯 exam tip, ⚠️ warning, 📝 probable questions, 🔑 key point.
2. **Write** — har unit ke baad 2 long answers bina notes dekhe likho (numericals me especially).
3. **Revise** — har unit ka ⚡ Rapid Revision box; poora semester ~30 min me revise ho jaata hai.
4. **Before exam** — sirf rapid revision + probable questions + formats.
