UNIT 1 — Introduction & Evolution of Computers

1.1 Computer kya hai?

Computer = ek electronic machine jo input leti hai, usko process karti hai (diye gaye instructions ke hisaab se), aur output deti hai — aur saath hi data ko store kar sakti hai. Iska kaam kisi program (instructions ka set) ke control me hota hai, apne aap nahi.

Aasan bhasa me: Input → Process → Output + Storage — yahi computer ka chakra hai.

        +-------------------+
Input ->|   PROCESSING      |-> Output
        |   (CPU + Memory)  |
        +-------------------+
                 |
              STORAGE
   (Input devices: keyboard, mouse, scanner, mic)
   (Output devices: monitor, printer, speaker)
   (Processing: CPU - ALU + CU + Registers)
   (Storage: HDD, SSD, Pen drive, Cloud, RAM)

1.3 Characteristics of Computer (Features — 8 points)

FeatureMatlab
1. SpeedLakhon calculations per second — days ka kaam seconds me. Speed: nanosecond, picosecond me naapi jaati hai
2. Accuracy (shudhta)Calculation me galti nahi — galti sirf human input me hoti hai (GIGO)
3. Diligence (mehnat/lagatar)Thakta nahi, bore nahi hota, 24x7 kaam kar sakta hai
4. Versatility (bahu-mukhi)Ek hi machine — typing, drawing, gaming, accounting, video editing, AI
5. Storage capacityGB/TB me data store — pen drive me hazaaron books, photos
6. AutomaticEk baar program do, khud kaam karega (robot assembly line)

8. No feelings/emotionsUska mood nahi hota — par AI chat me "humans jaise" feel dena programming hai

Limitations of Computer (kaunse kaam nahi kar sakta)

  • No self-thinking: Instructions ke bina kuch nahi kar sakta — "zero IQ" machine.
  • No decision (without program): Khud se judgement nahi leta.
  • No feelings/emotions: Empathy, care, moral judgement nahi.
  • Dependency: Bijli, hardware aur software aur human operator chahiye.
  • Hardware failure ka risk: System crash, virus, data loss.
  • Unemployment ka concern: Automation se kuch jobs par asar.
  • Cost & maintenance: Setup aur regular maintenance mehnga.
Real life example: Railway reservation system (IRCTC) ek saath lakhon seats ka hisaab seconds me rakhta hai, 100% accuracy se — par "kis passenger ko emergency me priority deni hai" wo judgement railway staff lega, computer nahi. Yahi hai computer ki speed + insaan ki wisdom ka combination 👌

1.7 Registers (CPU ke andar ki tiny memory)

Register = CPU ke andar bani sabse tez, sabse chhoti storage location (bits ka group) jahan currently process ho raha data/address rakha jaata hai. Ye memory hierarchy me sabse upar hai (fastest, smallest, costliest).
RegisterKaam
Accumulator (AC)ALU ke calculation ka temporary result rakhta hai (jaise "ans" memory of calculator)
Program Counter (PC) / Instruction PointerAgli instruction ka address rakhta hai — "ab kya padhna hai"
Instruction Register (IR)Currently execute ho rahi instruction rakhta hai
Memory Address Register (MAR)Us address ko rakhta hai jahan se data laana/store karna hai
Memory Data Register (MDR)Memory se aaya/jaane wala actual data rakhta hai
General Purpose RegistersTemporary data ke liye (AX, BX, CX, DX jaise names assembly me)
Status/Flag RegisterResult ke conditions: zero, carry, overflow, sign — decision (if/else) me kaam aata hai

Instruction Cycle (CPU kaise kaam karta hai — 4 steps)

1. FETCH    - PC ke address se instruction memory se laao
2. DECODE   - CU samjhe ki instruction kya keh rahi hai
3. EXECUTE  - ALU/CU kaam kare (add, compare, move data)
4. STORE    - Result ko register/memory me rakho, PC ko next par badhao
   (ye cycle billions of times per second chalta hai - 3 GHz CPU = 3 billion cycles/sec)

Cache Memory & Virtual Memory (bonus concepts)

  • Cache Memory: CPU aur RAM ke beech ki super-fast chhoti memory — frequently used data ki copy rakhti hai. L1 (fastest, chhoti), L2, L3 (badi, thodi slow). Isse speed badhti hai.
  • Virtual Memory: Jab RAM full ho jaaye, to computer HDD/SSD ke ek hissa ko "RAM jaisa" use karta hai (page file/swap). Slow hota hai par crash nahi hone deta.
  • Buffer: Temporary holding area — jaise printer spool, YouTube video ka buffering.
  • BIOS: Basic Input Output System — ROM me likha program jo komputer start karte waqt POST (power-on self-test) karke OS load karta hai.

2.4 CPU & Memory kaise kaam karte hain (step-by-step)

Jab tum "Excel" par click karte ho:
1. HDD/SSD se Excel ka program code RAM me load hota hai
2. CPU ka CU instruction fetch karta hai (Memory se RAM se)
3. Decode -> Execute: ALU calculations karta hai, values register me aati hain
4. Result RAM me jata hai, screen par display (output) hoti hai
5. Tum file save karte ho -> RAM se HDD/SSD me data likha jaata hai
Speed note: Register > Cache > RAM > SSD > HDD > Cloud (network)
Isliye RAM 8 GB se 16 GB karne par laptop "fast" feel hota hai - kam swapping.

2.5 Number System & Conversions

Number System = numbers likhne ka tarika — base/rataank ke aadhaar par. Computer binary (2) me kaam karta hai par human decimal (10) me sochta hai; isliye conversion aata hona zaroori hai.
SystemBaseDigitsExampleKahan use
Binary20, 1(1011)₂ = 11Machine language — computer ki bhasha
Octal80–7(17)₈ = 15Purane systems, UNIX permissions
Decimal100–9(25)₁₀ = 25Human counting
Hexadecimal160–9, A–F(1F)₁₆ = 31Memory address, colour codes (#FF0000), machine code likhna

(A) Decimal to Binary — Division method

Example 1: (25)10 = ?
25 / 2 = 12 remainder 1  (LSB - last likhna)
12 / 2 =  6 remainder 0
 6 / 2 =  3 remainder 0
 3 / 2 =  1 remainder 1
 1 / 2 =  0 remainder 1  (MSB - sabse pehle likhna)
Jawab (neeche se upar padho): 11001
=> (25)10 = (11001)2

Example 2: (45)10 = ?
45/2=22 r1, 22/2=11 r0, 11/2=5 r1, 5/2=2 r1, 2/2=1 r0, 1/2=0 r1
=> neeche se upar: 101101
Jawab: (45)10 = (101101)2

(B) Binary to Decimal — Power method

Har bit ko 2 ki power se multiply karo (right se left: 2^0, 2^1, 2^2...)
Example 1: (11001)2
= 1x2^4 + 1x2^3 + 0x2^2 + 0x2^1 + 1x2^0
= 16 + 8 + 0 + 0 + 1 = 25
=> (11001)2 = (25)10  ✅ (upper wale ka ulta - sahi hai!)

Example 2: (101101)2
= 1x32 + 0x16 + 1x8 + 1x4 + 0x2 + 1x1
= 32+8+4+1 = 45
=> (101101)2 = (45)10  ✅

(C) Decimal ↔ Hexadecimal / Octal, aur Binary-Octal-Hex shortcut

Decimal to Hex (16 se divide):
(255)10: 255/16 = 15 r 15 (F)   => 15/16 = 0 r 15 (F)
Jawab: (255)10 = (FF)16  (koi bhi colour code dekho: #FF0000 me FF hai)

Binary to Hexadecimal (4-4 bits ka group banao):
(1101 1010)2 -> 1101 = D (13), 1010 = A (10) -> (DA)16

Binary to Octal (3-3 bits ka group banao):
(101 110)2 -> 101 = 5, 110 = 6 -> (56)8

Hex to Decimal:
(2A)16 = 2x16 + 10 = 42  => (2A)16 = (42)10
Shortcut yaad karo: Decimal→Binary = Division method, jawab neeche se upar. Binary→Decimal = Power method (2^0 se badhao). Binary→Octal = 3 bits ka joda, Binary→Hex = 4 bits ka joda. Aur haan: 2^0=1, 2^1=2, 2^2=4, 2^3=8, 2^4=16, 2^5=32, 2^6=64, 2^7=128, 2^8=256 — ye table ratta maar lo (conversion me sabse zyada kaam aata hai) ✅

Boolean Algebra = George Boole (1854) ka develop kiya gaya woh algebra jisme sirf do values hoti hain — TRUE (1) aur FALSE (0). Digital circuits (CPU ke andar ke hazaron gates) isi par chalte hain. Isme OR, AND, NOT jaise operations hote hain.

Basic Boolean Laws (identity yaad rakho)

LawExpression
IdentityA + 0 = A ; A · 1 = A
Null/DominationA + 1 = 1 ; A · 0 = 0
IdempotentA + A = A ; A · A = A
ComplementA + A' = 1 ; A · A' = 0
CommutativeA + B = B + A ; A·B = B·A

Real life example: Ghar me "AC chalu ho" ka logic lo — AC ON tab hi jab (door band ho) AND (temperature high ho). Ek bhi condition fail = AC nahi chalega (AND gate). Aur "light ON" jab switch se hi... ya remote se hi (OR gate). ATM me card + PIN (AND) check hota hai. Sirf card = kaam nahi, sirf PIN = kaam nahi. Isliye AND gate zindagi me har jagah hai 🔐
De Morgan's theorem likhne ka trick: "Bar todo to sign badlo" — (A+B)' me bar todne par '·' lagta hai aur (A·B)' me bar todne par '+' lagta hai. Exam me statement + truth table se verify karke likho, full marks.

UNIT 4 — Computer Networks & Internet

4.1 Computer Network kya hai?

Computer Network = do ya zyada computers ka wo connection jo hardware (cable, Wi-Fi) aur rules (protocol) se juda hota hai — taaki wo data/resource share kar saken (file, printer, internet, software).

Objectives / Advantages of Networking

  • Resource sharing: Ek printer, ek internet connection, ek server — sab use kar sakte hain (cost bachti hai).
  • Communication: Email, chat, video call — instant messaging.
  • File & data sharing: Ek jagah file rakh do, sab access kar lein.
  • Cost saving & efficiency: Software ki ek hi copy centrally manage ho jaati hai.
  • Backup & reliability: Data duplicate karke safety milti hai.
  • Centralised administration: IT staff ek jagah se sab manage karta hai.

Disadvantages

  • Setup cost (cables, switches, server, IT staff).
  • Security risk — hacking, virus, data leak.
  • System dependency — server down to poori company ka kaam rukta hai.
  • Management complex — IP, permissions, troubleshooting.
